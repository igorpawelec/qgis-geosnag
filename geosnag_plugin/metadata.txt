description=Standing dead tree (snag) detection on aerial orthophotos, from adaptel micro-segmentation and a random forest.
version=0.1.1
author=Igor Pawelec
email=igor.pawelec@urk.edu.pl
about=QGIS Processing provider for the pygeosnag Python package: a raster goes in, a GeoPackage of dead-crown polygons with a confidence score comes out. RGB+NIR, CIR and RGB orthophotos, an absolute probability threshold, an optional stand mask from forest-management polygons, an optional second forest on the merged object, and "Adapt model" to teach the detector a new scene from a few labelled points. The algorithms stay in the package; this plugin is glue. pygeosnag, pygeoadaptels and pygeopalette are bundled; numba, scipy, scikit-learn, joblib, rasterio, fiona and shapely are installed into QGIS's Python on first run. The models are downloaded on first use from the pygeosnag GitHub release.
